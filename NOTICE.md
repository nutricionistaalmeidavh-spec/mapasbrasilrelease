# Atribuição de dados

A atribuição mínima prevista para aplicações que renderizem dados derivados do OpenStreetMap é:

```text
© OpenStreetMap contributors
https://www.openstreetmap.org/copyright
```

A aplicação consumidora deve manter a atribuição visível ou acessível de forma compatível com as diretrizes aplicáveis enquanto dados derivados do OpenStreetMap forem exibidos.

O link de copyright também informa que os dados do OpenStreetMap são disponibilizados sob a Open Database License (ODbL).
